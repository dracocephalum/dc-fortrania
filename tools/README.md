# tools

Programs used to build this repository's products, run by hand or by a build,
and never published.

| Component | Purpose | Status |
|---|---|---|
| [`spice-translation`](spice-translation/README.md) | translates the SPICE Toolkit with Fortrania, and rewrites what the translation needs for the platform it runs on | active |

Each component has its own solution and `README.md`. To add one, follow
`agentics/rules/coding/csharp/csharp-new-project.md` (or `/new` in Claude Code)
— it appends the row here.
